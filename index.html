마감 순서 — 2층부터
Closing Order
매장은 지하 · 홀 · 2층 세 구역이다.

밤 11시가 지나면 미리 마감할 수 있는 구역은 먼저 마감해두는 것이 효율적이다. 그래서 2층 → 지하 → 홀 순서로 마감한다.

2층을 가장 먼저 마감하는 이유는 두 가지다. 손님이 제일 빨리 나가는 자리이고, 문을 닫아두면 손님들이 2층 공간이 있다는 걸 잘 모른다.
2층 안내 중단 시간
2F Seating Cutoff
아래 시간이 지나면 2층으로 손님을 안내하지 않는다. 그만큼 마감이 빨라진다.

· 일 · 월 · 화 · 수 — 밤 10시 30분부터
· 목 · 금 · 토 — 밤 11시부터

단, 10명 이상 단체 손님이 있거나 2층 예약이 있으면 어쩔 수 없이 안내한다.
11시 이후 좌석 안내
Late-night Seating
지하에 손님이 많고 홀이 비어 있는 경우, 11시 이후 새로 들어오는 손님은 지하로 안내한다. 손님을 한 구역에 모아야 홀을 먼저 마감할 수 있다.

금·토는 인원이 많으므로 10시~10시 30분 사이 서빙·호출이 잠깐 멈추고 바에서 칵테일을 만들지 않는 타이밍에 바로 진행한다. 칵테일 주문이 많이 들어오는 중에 하면 혼잡해진다.
쓰레기 배출분리수거한 것은 20시까지 위쪽 주차장 창고에 보관하고, 20시 이후부터 배출할 수 있다. 배출할 때는 모든 쓰레기를 주차장 문 앞 전봇대 옆에 쌓아둔다.

충전 방법
Charging
① 어댑터와 USB 케이블을 연결한다
② Micro-USB 잭을 충전 거치대에 연결한다

배터리 — 약 20시간 (호출 100회 기준 17시간)

주의 — 전용 AC 어댑터(5V 1A)가 아닌 9V 고속충전기를 쓰면 충전 회로가 손상될 수 있다. 전원은 AC 110~240V에 연결하고, USB 허브에 연결할 때는 어댑터 전원이 있는 장치를 쓴다.
화면 보는 법
Display
화면에는 미확인 메시지 수 · 현재 시간 · 알람 모드 · 배터리 잔량이 표시된다.

· 화면이 꺼진 상태에서 SET을 누르면 켜지고, 15초 뒤 자동으로 꺼진다
· 호출이 오면 소리·진동과 함께 호출 내용이 점멸한다
· 배터리 잔량은 오른쪽 위에 표시된다
· 메시지가 있을 때 ∨를 누르면 바로 확인할 수 있다
메시지 확인 · 삭제
Messages
· 전체 메시지 화면에서 SET을 누르면 개별 메시지를 볼 수 있다
· 메시지 내용은 숫자·영문·특수문자 최대 10자리
· 최대 20개까지 저장되고, 벨 모양 이미지 안에 아직 확인하지 않은 메시지 개수가 표시된다
· 개별 메시지 화면에서 SET을 1초간 길게 누르면 그 메시지 또는 전체 메시지를 지울 수 있다
설정 — 관리자용
설정 메뉴 들어가기
Settings Menu
① SET을 1초간 길게 누르면 비밀번호 입력창이 뜬다
② △를 3번 눌러 비밀번호 0000을 입력한다
③ △를 1번 눌러 설정 메뉴로 들어간다

설정은 벨 관리 / 소리·진동 / 화면표시 / 장치 관리 네 가지로 나뉜다. 나올 때는 ∨를 누른다.
벨 문구 입력하는 법
Text Input
벨 내용을 입력할 때 쓰는 버튼이다. 벨 등록·삭제·3버튼벨 설정에서 공통으로 쓰인다.

· SET 짧게 — 문자 증가
· SET 1초 길게 — 문자 타입 변경 (숫자 → 특수문자 → 영문)
· △ 짧게 — 자릿수 이동
· △ (점멸 멈춘 뒤) — 이모티콘 선택
· ∨ 짧게 — 메뉴 나가기
소리 · 진동 설정
Sound / Vibration
호출이 왔을 때 나는 수신음 타입을 바꾼다.

설정 메뉴 진입 → △ 1번(메뉴 이동) → 소리/진동(SET 1번) → △로 타입 선택, SET으로 확정 → ∨로 나옴

수신음 종류 — 소리 / 진동 / 소리+진동 / 무음
종류마다 각각 4가지 수신음이 있다. 기본값은 진동.
시간 설정
Clock
설정 메뉴 진입 → △ 2번(메뉴 이동) → 화면 표시(SET 1번) → 시간 설정(SET 1번) → 시간 입력 → ∨로 나옴

입력은 SET으로 숫자 증가, △로 자릿수 이동.

on — 설정한 시간이 표시된다 (예: 13:36:47)
off — 시간 대신 페이저 이름(ID)이 표시된다 (예: Pager GB-650)
3버튼벨 설정
3-Button Bell
3버튼벨의 각 버튼을 Call / Bill / Clr(삭제벨) 또는 별도 문구로 쓸 수 있다.

설정 메뉴 진입 → 벨 관리(SET 1번) → △ 3번 후 SET 1번(3버튼벨 설정) → 버튼별 기능 선택(SET으로 기능, △로 다음 버튼) → ∨로 이전 메뉴 → △ 1번 후 SET 1번(벨 등록) → SET 1번 누르고 문구 입력 → 3버튼벨을 눌러 등록

버튼별 선택 항목
· 1/3 버튼 — Call / 맥주
· 2/3 버튼 — Bill / 소주
· 3/3 버튼 — Call / Bill / Clr(삭제벨) / 호출

1-버튼 설정 — 버튼마다 다른 벨 내용을 등록해 쓰는 모드
3-버튼 설정 — 기본 기능 사용 (초기값 Call / Bill / Clr)

버튼마다 다른 문구를 쓰려면 1-버튼 설정으로 바꾼 뒤 모든 버튼을 각각 등록해야 한다.
주요 설정값
Options
· 소리/진동 — 기본 진동. 소리 / 진동 / 소리+진동 / 무음 중 선택
· 알람 시간 — 기본 1초, 0~60초
· 중복 수신 방지 — 기본 0초, 0~60초
· 표시 모드 — 기본 430. 430 / 440 / 350 / A10
· 시간 설정 — 24시간 디지털 시계
· 제품 정보 — 버전, 사용자 이름, 등록된 벨 개수 확인
· 자가 테스트 — 이상이 있을 때 직접 테스트
· 초기화 — 설정값과 등록된 벨을 전부 초기화 (주의)
업체 · 그룹 등록
Group Registration
제품에 고유 번호를 부여해 다른 기기와 섞이지 않게 하는 기능이다. (수신기 ST-5010과 함께 사용)

설정 메뉴 진입 → 벨 관리(SET 1번) → △ 1번 후 SET 1번 → 번호 입력 → ∨로 나옴

번호 입력은 SET으로 숫자 증가, △로 자릿수 이동.
업체번호 01~99번, 그룹번호 00~99번까지 설정할 수 있다.
삭제벨 등록
Clear Bell
호출된 번호를 수신기 화면에서 지우는 기능을 벨에 부여한다.

설정 메뉴 진입 → 벨 관리(SET 1번) → 벨 등록(SET 1번) → SET을 눌러 문구 입력 → 문자 점멸이 멈추면 △ 1번 → SET을 눌러 Ctr 이미지 선택 → 벨을 1회 누르면 "등록되었습니다" 표시

주의 — 삭제벨은 특수 이미지가 사용되지 않은 호출벨에만 쓸 수 있다.
벨 삭제
